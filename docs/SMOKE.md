# 手工冒烟清单

自动化测试（`pytest`）只覆盖纯逻辑与模型层。界面相关的回归靠这份清单，**每次改动后走一遍，约 8 分钟**。

> 约定：全部通过才算"这一版可交付"。有任何一条不过，记下现象再打 tag。

## 准备

```powershell
cd "C:\Users\elgin\Desktop\widegt 3.2"
python main.py                 # 带控制台，方便看日志
# 或双击 ClassManager.pyw      # 无控制台
```

## 主界面

- [ ] **1. 启动**：窗口最大化出现，无报错弹窗；标题形如「高三八班  班级管理系统」
- [ ] **2. 左栏**：时间每秒刷新（含日期与星期）；倒计时数字与 settings.json 里的 `countdowns` 一致
- [ ] **3. 左栏 logo**：市西中学图片贴住侧栏**底边**，点它弹出设置窗口
- [ ] **4. 课程表**：显示今天各节课；双击某节课 → 打开「调整课表」，改一格 → 关闭后主界面同步更新
- [ ] **5. 值日生**：显示今日 5 个职务；双击某格 → 打开「调整值日」，改一格 → 关闭后主界面同步更新
- [ ] **6. 消息**：显示 `message.html` 内容（含图片）；双击 → 打开消息编辑器
- [ ] **7. 应用链接**：图标网格显示；点图标能启动对应程序；右下角 `...` 弹出添加对话框；右键某个应用 → 删除 → 网格少一个
- [ ] **8. 随机点人**：点按钮 → 弹窗显示一个学生姓名（名字比按钮更醒目、加粗）；点「重试」换一个
- [ ] **9. 选中框**：点表格某个格子 → 点旁边空白 → 选中框消失

## 悬浮窗与托盘

- [ ] **10. 最小化按钮**：侧栏「最小化」（字号小、在设置入口下方）→ 窗口收起，右侧出现**半透明红色圆角**悬浮窗
  - 显示：时间 / 第 N 节 / 科目 / 下一节 / 最近一个倒计时
  - 文字不重叠、不被裁切
- [ ] **11. 自动收缩**：不动它约 20 秒 → 悬浮窗缩成右下角**灰色小方块**，显示「第N节 / 科目」
- [ ] **12. 点小方块** → 悬浮窗重新出现；点「返回主界面」（或点面板底部任意位置）→ 回到**最大化**主窗口
- [ ] **13. 点 ×**：窗口右上角 × → 程序**不退出**，收进悬浮窗；任务栏图标消失
- [ ] **14. 托盘**：托盘图标右键 → 显示主界面 / 显示悬浮窗 / 退出；点「退出」才真正关掉进程
- [ ] **15. 全屏应用**：开 PPT 全屏放映 → 悬浮窗是否挡视线；确认能用「返回」或托盘收起

## 设置窗口（Tab 在下方）

- [ ] **16. 通用**：改班级短名 → 保存 → 主窗口标题立即变化
- [ ] **17. 名单**：新增/删除/导入后保存 → 主界面「随机点人」用的是新名单
- [ ] **18. 课程 & 课表**：改一格 → 保存 → 主界面课程表更新；「导入课表」能识别 CSV 与 xlsx
- [ ] **19. 值日生生成**：点「刷新预览」有内容；点「生成」→ 覆盖确认 → 主界面值日更新
- [ ] **20. 倒计时**：改一个日期 → 保存 → 左栏倒计时立即刷新
- [ ] **21. 数据只在数据库里**：改一次名单/课表/值日/应用 → 退出重开 → 改动都还在
  - `%APPDATA%\ClassManager\data\` 里只有 `classmanager.db` / `settings.json` / `data.json`
- [ ] **22. 下载导入模板**：设置 → 通用 → 下载导入模板 → 打开应看到「名单/分组/课表/说明」四个 sheet
- [ ] **23. 退出程序**：设置 → 通用 → 「退出程序」→ 进程真的结束

## 边界情况

  - 选一个数字 → 确认 → 主界面课程表出现内容

## 首次使用向导

- [ ] **26. 空机器首次启动**：让 `%APPDATA%\ClassManager` 不存在再启动 → 出现「首次使用设置」向导
  - 左侧 **7 步**、当前步高亮；「上一步」在第 1 页是灰的
  - 名单页粘贴 3 个名字，右侧立即显示「共 3 人」
  - 课表页填一格，「下一步」才能继续
  - **作息页**：表头选星期切换周一~周五；每节 4 个下拉（开始时/分、结束时/分），分钟精确到 1
    - 「把本日复制到其余四天」生效，且各天仍可独立改
  - 值日页切到「按分组轮值」→ 出现「分成几组」，默认按名单平均分
  - 完成页显示汇总 → 完成 → 主窗口出现，课程表/值日生/名单都是刚填的
- [ ] **27. 作息真的存住了**：向导里把周三第 1 节改成 09:05 → 完成 → **重开程序** → 再进向导，周三仍是 09:05
- [ ] **28. 向导取消**：点「取消」→ 确认框 → 退出程序；**再启动仍会进向导**
- [ ] **29. 老用户不被拦**：删掉 `setup.json` 再启动 → **直接进主窗口**，不弹向导
- [ ] **30. 重跑向导（保留项）**：设置 → 通用 → 「重新运行设置向导」
  - 弹出勾选框，**默认全勾**（= 保留现有内容）
  - 取消勾选「学生名单」→ 向导里名单页应为空，其余页仍有内容
  - 直接点完成 → 主界面数据不变；弹「已完成」并给备份路径
- [ ] **31. 重置入口**：设置 → 通用 → 「删除全部数据…」
  - 第 1 重说明框写明要手动重开、并说明保留应用链接
  - 第 2 重要手打班级短名，打错不删任何东西
  - 第 3 重最终确认后 → 弹「数据已清空」，程序退出
  - 重开 → 进向导；`backup\<时间戳>\` 有旧数据；**应用链接仍在**
