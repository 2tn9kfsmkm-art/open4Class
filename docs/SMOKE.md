# 手工冒烟清单

自动化测试（`pytest`）只覆盖纯逻辑与模型层。界面相关的回归靠这份清单，**每次改动后走一遍，约 5 分钟**。

> 约定：全部通过才算"这一版可交付"。有任何一条不过，记下现象再打 tag。

## 准备

```powershell
cd "C:\Users\elgin\Desktop\widegt 3.2"
python Main.py
```

## 主界面

- [ ] **1. 启动**：窗口最大化出现，无报错弹窗；标题形如「高三八班  班级管理系统」
- [ ] **2. 左栏**：时间每秒刷新（含日期与星期）；倒计时数字与 settings.json 里的 `countdowns` 一致
- [ ] **3. 左栏 logo**：市西中学图片贴住侧栏**底边**，点它弹出设置窗口
- [ ] **4. 课程表**：显示今天各节课；双击某节课 → 打开「调整课表」，改一格 → 关闭后主界面同步更新
- [ ] **5. 值日生**：显示今日 5 个职务；双击某格 → 打开「调整值日」，改一格 → 关闭后主界面同步更新
- [ ] **6. 消息**：显示 `message.html` 内容（含图片）；双击 → 打开消息编辑器
- [ ] **7. 应用链接**：图标网格显示；点图标能启动对应程序；右下角 `...` 弹出添加对话框；右键某个应用 → 删除 → 网格少一个
- [ ] **8. 随机点人**：点按钮 → 弹窗显示一个学生姓名；点「重试」换一个

## 设置窗口

- [ ] **9. 通用**：改班级短名 → 保存 → 主窗口标题立即变化
- [ ] **10. 名单**：新增/删除/导入后保存 → 主界面「随机点人」用的是新名单
- [ ] **11. 课程 & 课表**：改一格 → 保存 → 主界面课程表更新；「导入课表」选一个 CSV 能正常识别
- [ ] **12. 值日生生成**：点「刷新预览」有内容；点「生成」→ 覆盖确认 → 主界面值日更新
- [ ] **13. 倒计时**：改一个日期 → 保存 → 左栏倒计时立即刷新

## 边界情况

- [ ] **14. 周末首次启动**：删掉 `%APPDATA%\ClassManager\datas\loadings\<今天> classlist.csv` 再启动 → 弹出「今天没有课表信息，按照星期几上课？」
  - 该对话框**只有一个「确认」按钮，且在右侧**
  - 选一个数字 → 点确认 → 主界面课程表出现内容
- [ ] **15. 关掉询问框**：同上场景，直接关掉弹窗 → 程序**不崩溃**；下次启动会**再次询问**

## 打包后（仅打包版本需要）

- [ ] **16. 干净目录启动**：把 `dist` 拷到别的路径（或没有 Python 的机器）→ 双击 exe 能启动
- [ ] **17. 数据落点**：确认 `%APPDATA%\ClassManager\datas\` 里生成了数据文件，exe 目录下没有新增可写文件
- [ ] **18. 样式完整**：按钮是深红、侧栏是深红、表格无白底 —— 说明 `stylesheet/` 带进包了
