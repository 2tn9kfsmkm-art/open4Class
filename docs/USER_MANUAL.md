# 班级管理系统 使用手册

> 适用于 1.0.x 版本　·　2026 年 11 月

本手册面向班级管理者（老师 / 班干部），按「装好 → 填数据 → 日用 → 维护」的顺序编写。

## 1 软件概览

班级管理系统（ClassManager）是给中学班级日常使用的一套桌面程序。它把每天要重复做的事集中到一块屏幕上：今天的课表、值日生、班级通知、距离重要考试的倒计时、常用软件入口，以及随机点名。

程序装在一体机或教师机上，主流配置是希沃等带触摸屏的教室设备。界面按 1080p / 4K 两种屏幕都做过适配，触摸和鼠标都能用。

### 1.1 它能替你做什么

| 模块 | 作用 |
|---|---|
| 今日课表 | 按星期自动显示当天各节课，不用每天手写 |
| 值日生 | 每天若干职务，按名单顺序或按分组自动轮值 |
| 消息 | 富文本通知，支持插图，双击即可编辑 |
| 倒计时 | 最多 3 个（高考、期末考等），显示在左栏并自动倒数 |
| 随机点名 | 从名单里随机抽一位同学，大字号显示，适合投屏 |
| 应用链接 | 一键启动 U 盘、WPS、希沃白板、浏览器等常用程序 |
| 悬浮层 | 最小化后顶部显示当前课与进度，右下角小窗随时回主界面 |
| 首次向导 | 第一次使用分步填好班级信息、名单、课表、作息、值日 |

程序不联网、不上传任何数据，所有内容只保存在本机。

### 1.2 运行环境与数据位置

| 项目 | 说明 |
|---|---|
| 操作系统 | Windows 10 / 11（64 位） |
| 屏幕 | 1080p 起；4K 与 250%–300% 缩放已适配 |
| 安装位置 | %LOCALAPPDATA%\ClassManager（当前用户目录，无需管理员） |
| 数据位置 | %APPDATA%\ClassManager |
| 数据库 | %APPDATA%\ClassManager\data\classmanager.db |

> **提示**　「安装位置」和「数据位置」是两回事。重装或升级程序不会动数据；卸载时也默认保留数据（安装向导里可以勾选一起删除）。

## 2 安装与第一次启动

### 2.1 安装

1. 从发布页面下载 ClassManager-Setup-x.y.z.exe。
2. 双击运行。如果 Windows 弹出「已保护你的电脑」，点「更多信息 → 仍要运行」。这是对未签名程序的默认拦截，不是报错。
3. 按提示下一步即可，装完桌面和开始菜单会有快捷方式。

> **提示**　若 360、电脑管家等安全软件拦截写入，请把安装目录加入信任区，否则程序可能存不住数据。

### 2.2 第一次打开：设置向导

第一次启动会自动进入「首次使用设置」向导。左侧是 7 个步骤，当前步高亮，填完可以随时点「上一步」回去改。

| 步骤 | 这一步做什么 |
|---|---|
| 欢迎 | 说明向导用途；如果老师已在网页端填好数据，可在这里输入传输码一次性导入 |
| 班级信息 | 学校名称、班级名称，选择主题色、上传学校图标（会显示在侧栏底部） |
| 学生名单 | 每行一个姓名，可直接粘贴，也可导入表格；顺序就是值日轮值顺序 |
| 课程表 | 导入或手动填写「周一~周五」的每周模板课表 |
| 作息时间 | 设置每节课的开始与结束时间，可先设一天再「复制到其余四天」 |
| 值日安排 | 选按名单顺序轮值，或按分组轮值；分组可由程序平均拆，也可导入 |
| 完成 | 显示汇总，点「完成」后才真正写入数据 |

向导里点「取消」会确认后退出程序，下次启动仍会继续要求完成设置；这是刻意设计的，避免半套数据被当成正式数据使用。

### 2.3 要准备的表格（可选）

不想手工输入的话，先把名单、课表、作息整理成 Excel 或 CSV，在向导对应页面点「导入」即可。最省事的做法是先在「设置 → 通用 → 下载导入模板（Excel）…」拿到模板，模板里含「名单 / 分组 / 课表 / 说明」四个工作表，按表头填就行。

| 内容 | 格式要求 |
|---|---|
| 名单 | 一列，表头写 name（写「姓名」也认），每行一个学生 |
| 课表 | 五列，表头为 周一 / 周二 / 周三 / 周四 / 周五，每行一节课 |
| 分组 | 每列一组：第一行是组名，下面各行是成员 |
| 作息 | 两种都行：①五列（周一~周五），每格写 7:30-8:10；②两列「开始 / 结束」，填了默认五天一致 |

导入支持 .csv 与 .xlsx。常见错误：表头写成「学生姓名」认不出；课表里把「没课」写成文字会被当成课程名，请留空。

### 2.4 换班级、重来一次

换班或数据填错了，不需要卸载重装，两个入口都在「设置 → 通用」：

- 「重新运行设置向导（保留现有数据）…」：重走一遍向导。弹出勾选框决定哪些内容保留，默认全勾；取消勾选「学生名单」，向导里名单页就是空的，其余页仍有内容。完成后旧数据会先自动备份。
- 「删除全部数据，重新开始首次使用向导…」：清空后从零开始。需要连过三道确认，其中一道要手打班级短名；完成后程序自动退出，再打开就是向导。旧数据备份到 backup 目录，应用链接默认保留。


## 3 主界面

### 3.1 布局

- 左侧栏：时间、日期、星期（每秒刷新），倒计时；底部是学校图标（点它 = 打开设置），图标下方是「最小化」按钮。
- 中间：今日课程表，下面是今日值日生。
- 右侧：班级消息、应用链接图标网格，以及随机点名按钮。

窗口启动即最大化。若首次打开没有铺满屏幕，最小化再恢复一次即可，这是高缩放比下的已知情况。

### 3.2 今日课表

按当天的作息与课表自动显示节次与科目。临时调课（换课、自习）直接双击表格里任意一格，打开「调整课表」窗口改完保存，主界面立即同步。这种改动只影响今天，不会改掉每周模板。

周末或节假日第一次启动时，如果还没有当天的课表，程序会问「今天没有课表信息，按照星期几上课？」：选一个数字就按那天上，也可以选「设置临时课表」手填。直接关掉这个框也不会出错，下次启动会再问。

### 3.3 值日生

显示今天各职务（如值日班长、扫地、拖地、擦黑板、倒垃圾）对应的人。临时换人同样双击那一格修改，只影响当天。

自动轮值在「设置 → 值日生生成」里做，见第 5 章。

### 3.4 消息

显示班级通知，支持粗体、字号、颜色和插入图片。双击消息区域打开编辑器，改完保存立刻生效。图片随消息一起保存在本机数据目录里。

### 3.5 应用链接

图标网格，点一下直接启动对应程序。右下角的「…」用来添加新应用；在某个图标上右键可以删除。应用名称支持中文，路径就是程序的 exe 或快捷方式。

### 3.6 随机点名

点按钮弹出窗口，随机显示一位同学，字号很大，适合投屏。点「重试」换一位。抽人范围就是名单里的全体，顺序不影响。

## 4 日常操作速查

| 想做的事 | 怎么做 |
|---|---|
| 今天的课临时换了 | 主界面课程表里双击那一格，改完保存 |
| 今天谁值日要换 | 值日栏双击那一格，改完保存 |
| 发一条班级通知 | 双击消息区域，编辑后保存 |
| 加一条考试倒计时 | 设置 → 倒计时，名称 + 日期，最多 3 条 |
| 换班级名 / 学校名 | 设置 → 通用，改「班级短名」（或全名、学校名称），保存 |
| 换个主题色 / 学校图标 | 设置 → 通用 → 选择颜色… / 选择图片… |
| 把课表给别的班用 | 设置 → 通用 → 下载导入模板（Excel）… |
| 电脑要重装 | 先把 %APPDATA%\ClassManager 整个复制走，装好后再复制回来 |
| 彻底重来 | 设置 → 通用 → 删除全部数据…（三重确认，会保留应用链接） |
| 暂离但保持课表可见 | 点侧栏「最小化」，进入悬浮层 |
| 真正退出程序 | 托盘图标右键 → 退出，或设置 → 通用 → 退出程序 |

## 5 设置窗口

### 5.1 打开与保存

点侧栏底部的学校图标打开设置。窗口下方是页签，共八页：值日生生成、名单、课程、作息、倒计时、应用链接、消息、通用。多数页面都是改动后点「保存」才生效，点「重置」放弃本次修改。

> **提示**　设置窗口关闭后会释放内存，反复开关不会越开越卡；但每个页面都请记得保存，关窗口不会替你保存。

### 5.2 各页签做什么

| 页签 | 作用 |
|---|---|
| 值日生生成 | 选「名单顺序轮值」或「分组表格轮值」，设职务与起始日期，「刷新预览」看结果，「生成」写入未来值日；也可「直接编辑未来值日」 |
| 名单 | 增删学生、导入表格、调整顺序（顺序即轮值顺序） |
| 课程 | 上半部是课程单（科目候选），下半部是周模板课表，可拖拽交换、增删节次、导入课表 |
| 作息 | 每节课的开始与结束时间，按星期分别设置 |
| 倒计时 | 名称 + 日期，最多 3 条，列表顺序就是在左栏的显示顺序 |
| 应用链接 | 添加应用、删除、上下移，决定主界面图标顺序 |
| 消息 | 与主界面双击打开的是同一个编辑器 |
| 通用 | 班级名称、主题色、学校图标、导入模板、重跑向导、清空数据、退出 |

### 5.3 通用页：外观

- 主题色：「选择颜色…」打开取色器，选完整套色阶自动派生；「恢复默认」回到深红。
- 学校图标：「选择图片…」换成自己学校的校徽，会显示在侧栏底部；「恢复默认」还原。

> **提示**　「打开调试控制台（开发用）…」只在排查问题时使用，日常不用点。

## 6 悬浮层与托盘

### 6.1 三种形态

在教室里最常见的需求是「课表一直看得见，但不挡板演」。程序用三层形态解决：

| 形态 | 怎么进入 | 显示什么 |
|---|---|---|
| 主窗口 | 正常启动 / 点「返回主界面」 | 完整功能，最大化铺满 |
| 悬浮面板 | 点侧栏「最小化」；或点窗口右上角 × | 时间、第 N 节 · 科目、下一节、最近一个倒计时 |
| 右下角小方块 | 悬浮面板约 20 秒不动自动收缩 | 第 N 节 + 科目，点一下变回面板 |

顶部长条会显示本节课的进度，随上课时间推进。

> **提示**　点 × 不是退出：程序会收进悬浮层继续待命，任务栏图标消失。真要退出，用托盘右键「退出」或「设置 → 通用 → 退出程序」。

### 6.2 托盘

屏幕右下角通知区域的程序图标，右键有：显示主界面 / 显示悬浮窗 / 退出。触摸屏上不好右键时，用「返回主界面」按钮或点小方块回到主窗口更顺手。

### 6.3 全屏放映 PPT 时

全屏放映会盖住一切窗口。这时课表其实还在后台，退出放映就回来了。如果希望放映时也看到时间与节次，可以把悬浮面板留在最上层，放映前先缩小成小方块，占用更小。

### 6.4 触摸屏使用

页面内容可以用手指直接拖动滚动（不需要去抓右侧那条细滚动条）。表格里的单元格仍然是双击进入编辑。

## 7 数据、备份与迁移

所有数据都在 %APPDATA%\ClassManager 里。直接复制这个文件夹，就等于备份了整台机器的班级数据。

| 路径 | 内容 |
|---|---|
| data\classmanager.db | 名单、课表、作息、值日、倒计时、应用链接 |
| data\settings.json | 界面设置：班级名、主题色、显示项等 |
| data\data.json | 最近登录日期等运行状态 |
| messages\ | 班级消息与其中的图片 |
| backup\ | 重跑向导、清空数据前的自动备份（按时间戳分目录） |
| debug.log | 运行日志，出问题时最有用的东西 |

换电脑：把整个 %APPDATA%\ClassManager 复制到新机器的同一位置即可，不需要重跑向导。请注意这台机器上不要同时开着两份程序——程序有单实例限制，第二个实例只会把已开的窗口叫到前台。

## 8 常见问题

#### 双击没反应、或一闪就没了

先看 %APPDATA%\ClassManager\debug.log 的最后几行。如果是被安全软件拦了写权限，日志里会有「数据目录不可写」之类的记录，把安装目录加入信任区即可。

#### 打开时提示「已保护你的电脑」

程序还没有代码签名，这是 Windows 的默认提示。点「更多信息 → 仍要运行」。

#### 窗口没铺满屏幕 / 字太大或太小

高缩放比（250%–300%）下程序会自动缩一点字号。若窗口没铺满，最小化再恢复一次即可；仍然异常请把 debug.log 里以 [startup] 开头的行发给我们。

#### 课表时间不对

时间来自「设置 → 作息」，与课表内容分开维护。改完作息不需要重启。

#### 卸载会不会删掉数据

默认不会。安装向导里有一个勾选项，勾上才会连同 %APPDATA%\ClassManager 一起删除。

#### 能不能两台电脑共用一份数据

不建议直接共用。程序面向单机使用，同时运行会互相覆盖。两台机器各存一份，需要同步时用「复制整个 %APPDATA%\ClassManager」的方式手动同步。

## 9 版本与反馈

本手册对应 1.0.x 系列。界面细节可能随版本微调，以实际程序为准。发现问题时，附上 debug.log 对应时间段的日志、以及操作步骤，排查会快很多。

## 附录 A 使用节奏（建议）

班务管理的麻烦往往不在「会不会用」，而在「什么时候该改」。下面这份节奏供参考，按实际校历调整。

| 周期 | 要做的事 |
|---|---|
| 每天 | 早上看一眼课表与值日是否正确；临时调课、换值日当场双击改掉 |
| 每周 | 检查消息是否需要更新；确认下周的值日已经生成；顺一遍应用链接是否还有效 |
| 每次考试前 | 更新倒计时名称与日期（最多 3 条，按重要性排序） |
| 每学期 | 换作息、换名单、换课表；用手册第 2 章的向导重跑一次最省事 |
| 换电脑 / 重装系统前 | 把 %APPDATA%\ClassManager 整个复制到 U 盘，装好再复制回来 |

### A.1 出问题时先做这三件事

1. 看 %APPDATA%\ClassManager\debug.log 的最后 50 行，找到时间点对应的那一段；
2. 回忆刚才点过什么：哪一步、点了哪个按钮、有没有弹窗；
3. 把这两样一起发出来，比只说「用不了」能省下几轮来回。
