# 导入格式说明

程序中所有"导入"都支持 **.csv** 和 **.xlsx**。
最省事的做法：设置 → 通用 → **下载导入模板（Excel）**，直接在里面填。

---

## 1. 名单

| 要求 | 说明 |
|---|---|
| 列数 | 1 列 |
| 表头 | `name`（也接受"姓名"） |
| 内容 | 每行一个学生，顺序就是值日轮值顺序 |

```csv
name
张三
李四
王五
```

常见错误：

- 表头写成"学生姓名""名字" → 认不出，按空处理
- 姓名里带空格（如"曾   域"）→ **允许**，程序保留原样
- 有重复姓名 → 会被合并去重

---

## 2. 课表

| 要求 | 说明 |
|---|---|
| 列数 | 5 列 |
| 表头 | `周一` `周二` `周三` `周四` `周五` |
| 内容 | 每行一节课；空格或空单元格表示"没课" |

```csv
周一,周二,周三,周四,周五
语文,数学,英语,物理,化学
数学,语文,物理,化学,英语
```

常见错误：

- 列顺序颠倒 → 按列名匹配，不按位置，但仍建议用标准顺序
- 多出"周六"列 → 会被忽略
- 单元格写"无""没课" → 会被当成课程名，请留空

---

## 3. 分组

| 要求 | 说明 |
|---|---|
| 结构 | **每列一组**（不是每行一组） |
| 第一行 | 组名，如"第一组" |
| 下面各行 | 该组成员 |

```
第一组,第二组,第三组,第四组
张三,王五,陈七,周九
李四,赵六,吴十,郑十一
```

常见错误：

- 写成"每行一组" → 组数和成员会错位
- 组名为空 → 该列被跳过

---

## 4. 不需要模板的内容

值日表、消息、倒计时、应用链接都在程序内生成或维护，不涉及导入。
