# 行为准则

> 中文 ｜ [English](#english)

本项目是几个高中学生维护的班级工具。
为了让它保持可协作，请在 issue、PR、讨论和代码注释里遵守下面几条。

## 期望的行为

- **就事论事**：批评代码、方案、截图，不评价人。
- **假设对方是好意**：多数分歧来自信息不对称，先问清楚再下结论。
- **给出可复现的信息**：说「点了哪里、看到什么、期望什么」，比「坏了」有用。
- **接受维护者的取舍**：这是课余项目，维护者有权拒绝不合适的改动。

## 不可接受的行为

- 人身攻击、嘲讽、歧视性言论（性别、地域、学校、成绩、身体等）。
- 骚扰、跟踪、反复在别人明确拒绝后继续纠缠。
- 未经允许公开他人的私人信息（真实姓名、联系方式、住址、社交账号）。

## 学生数据

本程序处理的是**真实的班级数据**——学生姓名、值日安排、班级照片。
因此：

- **不要**在 issue / PR / 截图里贴真实的学生姓名、照片、班级课表。
- 需要举例时用「张三 / 李四 / 王五」这类假名，或把截图里的名字打码。
- 需要附日志时，先确认 `debug.log` 里没有混进学生姓名（一般是有的，请自行替换）。
- 不要把别人的 `%APPDATA%\ClassManager` 目录整个上传。

违反这条的内容会被直接删除，不另行通知。

## 处理方式

维护者可以：编辑或删除不当内容、关闭 issue / PR、在严重或反复的情况下
屏蔽账号。判断标准是「是否让其他人不愿再参与」，而不是「谁更占理」。

## 举报

- 一般问题：在相关 issue 里 @ 维护者，或开一个 issue 说明。
- 涉及隐私泄露、安全问题的：**不要开公开 issue**，走
  [SECURITY.md](SECURITY.md) 里的私有渠道。

# English

> [中文](#行为准则) ｜ English

This project is a classroom tool maintained by a few high-school students. To keep it collaborative,
please follow the rules below in issues, pull requests, discussions and code
comments.

## Expected behavior

- **Criticize the work, not the person.** Disagree with code, designs, screenshots.
- **Assume good faith.** Most disagreements come from missing context — ask first.
- **Be reproducible.** "I clicked here, saw this, expected that" beats "it's broken".
- **Accept maintainer decisions.** This is a spare-time project; maintainers may
  decline changes that don't fit.

## Unacceptable behavior

- Personal attacks, mockery, discriminatory remarks (gender, region, school,
  grades, appearance, etc.).
- Harassment, stalking, or pestering someone after they have said no.
- Publishing someone's private information without permission (real name,
  contact details, address, social accounts).

## Student data

This app handles **real classroom data** — student names, cleaning-duty rosters
and class photos. Therefore:

- **Never** post real student names, photos or timetables in issues, pull
  requests or screenshots.
- Use placeholder names such as "Zhang San / Li Si", or blur the names.
- Before attaching a log, check whether `debug.log` contains student names
  (it usually does) and replace them.
- Do not upload anyone's whole `%APPDATA%\ClassManager` folder.

Content that breaks this rule is removed without notice.

## Enforcement

Maintainers may edit or delete inappropriate content, close issues or pull
requests, and block accounts in serious or repeated cases. The test is "does
this make others unwilling to participate", not "who is more right".

## Reporting

- General concerns: mention a maintainer in the relevant issue, or open one.
- Privacy leaks or security issues: **do not open a public issue** — use the
  private channel described in [SECURITY.md](SECURITY.md).
